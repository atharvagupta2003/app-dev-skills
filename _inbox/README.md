# Inbox

A place for raw, unsorted notes before they become skills. Write each note as: what happened, the cause, the fix, the general rule. Then distil it into the right skill following [AUTHORING.md](../AUTHORING.md).

Raw notes are kept out of the published tree. `_inbox/learnings.md` is listed in `.gitignore`, so a working log can sit here locally without being committed. Only this README is tracked.
